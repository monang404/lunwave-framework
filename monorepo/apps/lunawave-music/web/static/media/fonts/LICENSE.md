# Font Licenses — radio_toggle_redesign (R1.1)

Kedua font di bawah ini self-hosted (bukan CDN), sesuai R-D3. Subset diambil
dari paket [Fontsource](https://fontsource.org) (build resmi self-hostable
dari font sumber, distribusi via npm registry), bukan diunduh langsung dari
Google Fonts.
