# Security Policy

## Supported Versions

Only the latest `main` branch is actively supported for security updates.
Please ensure you are running the latest version of LunaWave.

## Reporting a Vulnerability

If you discover a security vulnerability within LunaWave, please send an e-mail to the repository owner or open a Private Security Advisory via GitHub.

We will review the report and respond within 48 hours.

**Please do not report security vulnerabilities through public GitHub issues.**
